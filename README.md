# Simple Inventory Management System

ITS203 Object-Oriented Design and Programming – Assessment C

A C# Windows Forms desktop application for small-business inventory management.

## Features
- Add, view, search, update and delete products
- Update stock quantities
- Low-stock identification
- Inventory/stock value calculation
- Input validation
- JSON data persistence
- Object-oriented `Product` and `Inventory` classes
- Separate JSON storage service

## Requirements
- Visual Studio 2022 or later
- .NET 8 SDK
- Windows

## Run
Open `SimpleInventoryManagementSystem.sln` in Visual Studio, or open the `.csproj` file directly and press F5.
